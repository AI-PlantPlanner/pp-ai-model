# 추천 모델 설계안 (백로그 6번) — 2026-11-07 초안

원칙: 모든 선택에 근거(문헌 또는 직접 실험)를 단다. 문헌이 없는 선택은 **미리 정한 후보를 학습용 종 안에서만 비교하는 실험**으로 정하고,
평가용 종은 그 과정에 쓰지 않는다(결과를 보고 고르는 순환 방지 — 연도 실험과 같은 원칙).

## 1. 모델이 하는 일
- 입력: 식물 1개(원예 자료 수치) + 1년(365일) 기후 그래프
- 출력: 그 기후가 그 식물의 자생지 기후와 얼마나 닮았는가(온습도 적합도 0~1)
- 학습: 자생지 짝(식물 ↔ 그 식물이 관측된 칸의 1년 기후)은 높게, 다른 기후는 낮게
- 추천할 때: 사용자 방의 1년 그래프를 넣어 100종 각각의 적합도를 낸다. 광량·추천 제외는 규칙이 맡는다(09-30 결정, 7번에서 결합).

근거: 09-30 설계(`모델 재설계 방향.pdf`) — "정답은 규칙이 아닌 관측 데이터", CLIP식 두 인코더 정렬. 10-28 원예팀 회신 — 자생지는 온습도 보조, 한계 하한은 평가용이라 입력 제외.

## 2. 결정 항목과 근거

### 2-1. 학습 목표(손실) — 후보 2개를 실험으로 결정
- A. 대조 손실(InfoNCE, CLIP: Radford et al. 2021) — 09-30 설계안. 배치 안 다른 식물을 음성으로 쓴다.
- B. 출현-only 손실 "assume-negative full"(SINR: Cole et al. 2023 ICML) — 원문 확인(11-07): "No loss is best in every setting"이지만 L_AN-full이 "most of the time" 다른 손실보다 낫고 범위 추정 과제(S&T·IUCN)에서 "decisive advantage". 무작위 칸을 의사 음성으로 쓴다. 원문 입력은 위치 좌표·환경 변수(시계열 아님).
- 결정 방법: 학습용 종 안의 내부 검증 성능으로 고른다. 이유: A는 자생지가 겹치는 식물(예: 열대 관엽끼리)을 서로 음성으로 밀어내는 문제가 있고, B는 이를 피하지만 원 논문은 위치 입력 기준이라 우리 설정(기후 시계열)에서 검증된 적 없음.

### 2-2. 기후 입력
- 변수: 일 최저·평균·최고 기온, 일평균 상대습도 + 시간 열(낮 길이, 연중 위치). 일사량은 넣지 않는다(광량은 규칙 담당, 09-30).
  - 시간 열 근거: 09-30 설계 "계절이 반대여도 같은 기준으로 읽게" — 낮 길이가 남반구 계절을 표현(데이터 단계에서 날짜 이동 근거를 못 찾아 미룬 문제의 해결).
- 단위: **칸 × 1개 연도**를 한 표본으로, 학습 때마다 10년 중 무작위 연도를 뽑는다.
  - 근거 ① 추천 때 입력이 게임의 1년 그래프 → 학습과 추론의 입력 형식을 맞춤. ② 연도 실험: 추위 쪽은 1년으로도 0.888(10년 0.889)이라 1년 단위로 정보 손실이 적음, 더위 쪽은 1년이 약해 여러 해를 번갈아 보여 주는 편이 낫다(10년 평균을 한 번에 넣으면 실제 1년 그래프보다 매끈해져 추론 입력과 달라짐).

### 2-3. 기후 인코더 — 주 모델 PatchTST + 비교 2개
- 주: PatchTST(Nie et al. 2023 ICLR) — 09-30 설계안. 원문 확인(11-07): 지도학습 기본 P=16·S=8, "P between {8, 16} seems to be general good numbers", 패치 길이에 결과가 크게 변하지 않음(robust). 사전학습 실험은 겹치지 않는 패치 12, 가림 40%. → 사전학습은 원문 설정(겹침 없음, 40%)을 따르고 패치 길이는 {8, 16} 중 내부 검증으로.
- 사전학습: 칸 84,340개 × 10년(약 84만 개 1년 그래프, 라벨 없음)으로 가리고 복원하기. 근거: PatchTST 원문 "on large datasets our pre-training procedure contributes a clear improvement compared to supervised training from scratch". 원문의 과제는 예측(forecasting)이라 우리 과제(표현 학습 후 정렬)로의 효과는 부품 제거 실험(사전학습 없음)으로 직접 확인한다.
- 비교(부품 제거 실험): ① 사전학습 없음 ② 손으로 만든 기후 요약(베이스라인 지표 8개) + 작은 MLP.
  - 근거: 중간 규모(약 1만 표본) 표 자료에서 트리 모델이 딥러닝보다 낫다는 보고(Grinsztajn et al. 2022 NeurIPS)가 있어 "시계열 인코더가 요약 통계보다 나은가"를 직접 보여야 함.

### 2-4. 식물 인코더 — 작은 MLP, 입력은 원예 자료
- 입력: 적정 온도, 적정 습도, 광량 관련 값, 기후형, 생육형 그룹, 재배구분.
- **제외: 한계온도 하한·상한** — 평가 정답이므로 넣으면 누설(10-01 파일럿에서 발견한 설계 문제, 10-28 원예팀 회신과 일치).
- 기후형은 자생지 기후와 직접 관련된 원예 정보라 넣되, "기후형 없이" 비교도 한다(베이스라인에서 0.89의 대부분이 기후형 차이였으므로).

### 2-5. 학습 데이터
- 본 세트 76식물/75종(데이터 카드). 같은 종을 가리키는 두 식물(디펜바키아·트로픽스노우)은 같은 묶음으로 다룬다.
- 종마다 기록 수가 30배 이상 차이 나므로, 배치에서 종을 고르게 뽑는다(종 균형 추출). 근거: 대조 학습·SINR 모두 종 단위 손실이라 기록 많은 종이 학습을 지배하지 않게 함 — 실험으로 확인할 항목에 포함.
- 품종 제외 세트로 같은 실험 한 번(B 결정의 감도).

### 2-6. 평가 — 두 가지 설정을 구분
같은 "0.89"라도 무엇을 아는 상태에서 맞혔는지가 다르므로 설정을 나눈다.

**설정 1. 학습에 없던 식물(주 실험)**: 종 단위 5겹 교차검증(Roberts et al. 2017 Ecography — 묶음 구조가 있는 자료는 묶음 단위로 나눠야 오차를 과소평가하지 않음). 기후형 비율을 겹마다 맞춤. 평가 식물의 GBIF 기록은 학습에 쓰지 않는다.
- 지표 ① 자생지 맞히기: 평가 식물의 실제 관측 칸 vs 무작위 칸 구분(AUC)
- 지표 ② 추위 한계: 모델이 "적합"으로 본 칸들의 추위 지표(하위 5%)를 원예 한계 하한과 비교 — 순위 상관(전체·기후형 안)과 오차(℃)
- 비교 대상: (a) 원예 자료만으로 한계 하한을 맞히는 회귀(같은 입력, 정답 사용) (b) 같은 기후형 평균 (c) 베이스라인 0.889 = **그 식물의 GBIF를 직접 쓴 값이라 상한 참고치**(설정이 다름을 명시)

**설정 2. 학습에 있던 식물**: 전 종으로 학습 후, 모델이 그 식물에 대해 낸 추위 지표를 단순 통계(5번)와 비교 — 같은 정보를 쓴 공정 비교. 주장 후보: "같은 기후형 안 구분(온대 0.42) 개선", "오차 5.5℃ 개선".

- 반복: 시드 5개 평균 ± 표준편차.
- 후보 선택(손실 A/B, 패치 길이, 크기)은 학습용 겹 안의 내부 검증으로만.

## 2-7. 근거 수준 (11-07 점검)
- 원문 확인: SINR 손실 비교, PatchTST 패치·가림·사전학습 효과(위 인용).
- 원문 확인(11-07 추가): Roberts 2017 — "regularly ignored, resulting in serious underestimation of predictive error", 묶음 방식에 "blocking by hierarchical groups"·"phylogenetic blocking" 포함, "block cross-validation is nearly universally more appropriate than random". 종 단위 분할 = 묶음(group) 차단. 주의: 묶음 차단은 외삽을 강제할 수 있다고 원문이 경고 → 설정 1이 외삽 평가임을 명시.
  Grinsztajn 2022 — "tree-based models remain state-of-the-art on medium-sized data (∼10K samples)", 표본 3,000 미만 자료는 벤치마크에서 제외 → 우리 규모(75종)에 직접 적용되는 결과는 아님, "단순 모델과 비교가 필요하다"는 근거로만 사용.
  CLIP(Radford 2021) — N개 짝 배치에서 N²−N개 틀린 짝과 대조하는 "symmetric cross entropy loss", InfoNCE(Oord 2018).
- 문헌 없이 우리 근거로 정한 것 → 모두 부품 제거 실험으로 확인:
  · 무작위 1개 연도 입력(근거 = 게임 입력 형식 + 연도 실험) → "10년 평균 입력"과 비교
  · 종 균형 추출(직접 문헌 없음) → "균형 없음"과 비교
  · 모델의 추위 지표 = "적합으로 본 칸들의 하위 5%" — 베이스라인·파일럿과 같은 연산이라 비교 가능하다는 것이 근거(새 정의 아님)
  · 시드 5개 = 관행(문헌 미확인)

## 3. 실험 순서
1. 데이터 연결 코드(식물·칸·연도 → 텐서), 기후 값 메모리 적재(float16 약 2.5 GB)
2. 사전학습(PatchTST 가리고 복원하기)
3. 손실 A/B 비교(내부 검증) → 선택
4. 설정 1 교차검증 + 비교 대상
5. 설정 2
6. 부품 제거: 사전학습 없음 / 요약통계+MLP / 기후형 없음 / 10년 평균 1개 입력(무작위 연도 대신) / 종 균형 추출 없음 / 품종 제외 세트

## 4. 환경
- Apple M4, 메모리 16 GB, PyTorch 2.15.0 MPS(11-07 설치·동작 확인).

## 3-1. 데이터 연결 결과 (11-07, `src/model_data.py`)
- 기후 캐시: (연도 10, 칸 84,340, 365일, 변수 4) float16 2.46 GB + 낮 길이 (칸, 365). 메모리 맵으로 읽음, 512개 배치 0.005초.
- 점검: 원본 parquet와 최대 차이 0.03℃(float16 반올림), cold_ext 10년 평균 재계산이 베이스라인 칸 요약과 최대 0.007℃ 차이, NaN 0.
- 입력 채널 7개: 기온 3·습도(전체 칸 평균·표준편차로 표준화) + 낮 길이 + 연중 위치 sin·cos.
- 식물 입력 23차원: 수치 12개(적정 온도·습도·광량·광주기, 학습 겹 식물로 표준화) + 원핫 11개(기후형 4·생육형 그룹 4·재배구분 3). 한계온도 4열 제외.
- 5겹 분할 `data/dataset/folds.csv`(seed 0, 결과 보기 전 고정): 겹마다 15종(식물 15~16), 온대 6종씩. '열대·아열대'는 2종뿐이라 두 겹에만 들어감.
- 누설 점검: 평가 겹 종이 학습 배치에 안 나옴을 확인.

## 3-2. 사전학습 (11-08, `src/model_patchtst.py`, `src/pretrain.py`)
원문(arXiv 2211.14730 PDF)과 공식 코드(github yuqinie98/PatchTST, PatchTST_self_supervised)를 대조해 설정을 정함.
- 원문대로: 채널 독립(가중치 공유), 학습형 위치 임베딩, BatchNorm(post-norm), 층 3·헤드 16·D 128·F 256·GELU·드롭아웃 0.2(부록 A.1.4),
  겹침 없는 패치, 패치 40%를 0으로 가림(표본·채널마다 따로 — 공식 random_masking), 가린 패치만 MSE(공식 _loss), D×P 선형 헤드.
- 원문에 값 없음 → 공식 코드 기본값: Adam, lr 1e-4, one-cycle, 사전학습 에포크 10(`n_epochs_pretrain=10`; 원문 본문 100 에포크는
  훨씬 작은 데이터 기준. 100 에포크는 우리 데이터에서 패치 16 기준 약 16시간·패치 8 약 40시간이라 불가 — 검증 곡선으로 수렴 확인).
  공식 코드의 d_ff 512·ReLU는 원문 부록(F 256·GELU)과 달라 원문을 따름.
- 바꾼 것(근거):
  · 인스턴스 정규화(RevIN) 끔 — 기온 수준이 목표 정보. 원문 부록 A.4.4: 인스턴스 정규화 효과는 "slightly", 없이도 우수.
  · 365일 끝을 마지막 값 반복으로 채움(원문 본문 패딩 방식). 공식 코드는 앞을 잘라내 1월 초 추위가 빠지므로 안 씀.
    패치 16 → 23개(368일), 패치 8 → 46개(368일). 가림 개수는 공식 규칙(N − int(0.6N)) → 10개·19개.
  · 채널 5개(기온 3·습도·낮 길이). 연중 위치 sin·cos는 위치 임베딩과 같은 정보(모든 입력이 1/1 시작)라 제외.
- 데이터: 1년 그래프 843,400개 중 칸 2%(1,686칸 × 10년 = 16,860개)를 검증으로 통째 제외(seed 0), 학습 826,540개. 배치 256.
- 검증 가림 고정(생성기 seed 0) → 에포크 비교 가능. 같은 가림에서 비교 기준 2개: 0 채우기(=전체 평균), 앞뒤 선형 보간.
  전체 검증 16,860개(공식 값): 0 채우기 1.027, 선형 보간 0.240(채널별 t_min 0.175·t_mean 0.159·t_max 0.188·rh 0.657·낮 길이 0.022),
  학습 전 모델 1.050 → 보간이 강한 기준. 모델이 이것보다 낮아야 계절 구조를 배웠다고 말할 수 있음.
  (처음 검증 앞 2,000개로 본 예비값 0.680·0.149는 칸 번호순 앞 ~200칸만이라 지역이 치우친 값 — 쓰지 않음.)
- 속도(M4 MPS, 배치 256): 패치 16 0.18초/단계 ≈ 10분/에포크, 패치 8 0.45초/단계 ≈ 24분/에포크. 매개변수 약 40만 개.
- 트러블슈팅: MPS는 float64 미지원 → 집계를 CPU로 옮긴 뒤 float64 변환.

### 사전학습 결과 (11-08 실행, 패치 16 약 1.9시간 → 패치 8 약 4.3시간)
검증 가림 MSE(표준화 단위), 비교 기준은 **각 실행의 같은 가림**에서 계산:

| 패치 | 0 채우기 | 선형 보간 | 사전학습(10 에포크) | 보간 대비 |
|---|---|---|---|---|

## 3-3. 손실 A/B 비교 — 내부 검증 (11-09, `src/align.py`, `scripts_align_grid.sh`)
원문 재확인: SINR(arXiv 2306.02564) 식 5 L_AN-full, λ = 2048(47,375종, 부록 C.2, 정하는 규칙 없음), Adam lr 5e-4, 위치 인코더 폭 256(부록 C.1).
CLIP(Radford 2021) 의사코드 — L2 정규화 후 코사인 × exp(t), 대칭 교차 엔트로피, t 시작 0.07 상당, 배율 상한 100(2.5절).
PatchTST 4.2 — 선형 탐색 후 미세조정 2단계(Kumar et al. 2022 인용), 지도학습 머리 = 펼치기 + 선형(3.1).
- 기후 탑: 사전학습 인코더 + 펼치기 → 드롭아웃 0.2 → 선형 → 128, L2 정규화. (공식 분류 머리는 마지막 패치만 써서 1년 전체 대표에 부적합 → 원문 지도학습 머리)
- 식물 탑: MLP 23→256→256→128(ReLU, 드롭아웃 0.2), L2 정규화.
- 손실 A: 한 묶음에 학습 종마다 1개(같은 종 중복 없음), 묶음 G = ⌊256/종 수⌋개 평균 → 단계당 기후 수를 B와 맞춤.
- 손실 B: 양성 256(종 균형) + 무작위 칸 256(전체 육지 균등), ŷ = sigmoid(점수 + b). 같은 종의 다른 식물 행은 음성에서 제외.
  λ 후보 {1, R−1}: 1 = 가중 없음, R−1 = 양성 1개가 같은 칸 음성 전체와 같은 무게(R = 학습 식물 수). 원문 2048은 47,375종 기준이라 그대로 못 씀.
- 일정: 선형 탐색 1,000단계(인코더 고정, lr 5e-4) → 전체 미세조정 3,000단계(인코더 lr 1e-4, 나머지 5e-4). 250단계마다 내부 AUC, 최고 시점 저장.
- 내부 검증: 바깥 학습 종을 2분류(온대/열대·아열대)로 층화해 20%를 내부 검증 종으로(seed 0). 지표 = 종별 AUC(관측 칸 최대 1,000 vs 무작위 칸 5,000, 고정 연도) 평균. 원예 한계온도는 선택에 안 씀.
- 후보 6개: A·B(λ1)·B(λR−1) × 패치 16·8.
- 트러블슈팅: 4분류 층화 실패(겹 0 학습 종에 '열대·아열대' 1종) → 베이스라인과 같은 2분류로 층화.
- 시험 실행(겹 0, 각 40+40단계): 내부 AUC A·p16 0.73, B·p16·λR−1 0.80, B·p8·λ1 0.79 — 코드 동작 확인용, 결과로 쓰지 않음.
- 소요 추정: 겹당 약 4.2시간(B·p8가 가장 느림, 1.2초/단계) → 5겹 전부 약 21시간. 먼저 겹 0 전체 후보를 돌려 학습 곡선으로 필요한 단계 수를 보고 나머지 겹 계획을 정함.
