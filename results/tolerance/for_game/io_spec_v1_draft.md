# AIPlant 추천 입출력 명세 (초안 v1)

## 1. 전체 흐름

```
게임(Unity) ──365일 배열──▶ 추천 계산(recommend_v1.onnx, 게임 안에서 실행) ──점수·판정──▶ 게임 화면
```

- **점수 판정은 원예 규칙으로 합니다.** 탈락(0점)은 두 가지(한계온도 이탈, 재배구분 불일치)뿐입니다.
  감점은 원예 적정 범위 기준입니다.
- **AI 모델은 보조 정보를 줍니다.** 전 세계 자생지 관측으로 학습한 식물별 "건조 한계"와 비교해 경고를 붙입니다.
  경고는 점수에 넣지 않습니다.
- AI 모델(신경망)은 게임에 들어가지 않습니다. 모델 결과는 식물별 한계 값으로 미리 만들어 두고, **추천 계산 전체를 ONNX 파일(`recommend_v1.onnx`)로 제공합니다**(5절).

## 2. 입력 (놓는 위치 하나당 하나)

```json
{
  "placement_id": "room1_window_south",
  "cultivation_context": "실내",
  "daily": {
    "t_min":  [365개],
    "t_max":  [365개],
    "t_mean": [365개],
    "rh_mean": [365개],
    "light_lux_mean": [365개]
  }
}
```

| 필드 | 단위 | 설명 |
|---|---|---|
| `cultivation_context` | | `"실내"` 또는 `"실외"`. 재배구분 판정에 씀 |
| `t_min`, `t_max` | ℃ | 하루 중 최저·최고 기온. **탈락 판정이 이 값의 1년 최저·최고로 이루어짐** |
| `t_mean` | ℃ | 하루 평균 기온 |
| `rh_mean` | % | 하루 평균 상대습도 |
| `light_lux_mean` | lux | 낮 평균 밝기: 조도가 0보다 큰 프레임만 평균(밤 제외). 밤을 포함하면 어둡다고 잘못 판정됨 |

- 배열은 1월 1일부터 365일입니다(윤년이면 2월 29일 제외).
- **1년 평균 하나만 보내면 안 됩니다.** 평균에는 겨울 한파가 묻혀서, 겨울에 죽는 식물이 추천됩니다.

## 3. 입력을 요약하는 방법 (ONNX 안에서 함)

| 요약값 | 계산 | 쓰는 곳 |
|---|---|---|
| `t_min_year` | 365일 `t_min`의 최솟값 | 한계온도 하한과 비교 → 탈락 판정 |
| `t_max_year` | 365일 `t_max`의 최댓값 | 한계온도 상한과 비교 → 탈락 판정 |
| `t_mean`, `rh_mean`, `light_lux_mean` | 365일 평균 | 적정 범위와 비교 → 감점 |
| `rh_dry_p05` | 365일 `rh_mean`의 하위 5% 값 | 모델 건조 한계와 비교 → 경고 |

## 4. 바뀔 수 있는 것

1. 일부 식물 학명과 한계 값. 형식은 그대로입니다.
2. 모델 건조 경고를 점수에 넣을지(검토 중).
3. 낮 길이 입력: 꽃 피우는 식물의 점수 변환 방법이 정해지면 입력 하나가 추가될 수 있습니다.
4. **습도 계산 (확인 요청):** 실내 습도를 바깥 수증기량만으로 계산하는 방식(수증기량 보존식)이면 서울 겨울 실내 습도가 약 14%로 나옵니다.
   한국 아파트 겨울 실측 평균은 약 35%입니다(조준행·최윤정 2013, 20가구 23.0~54.1%).
   이 경우 대부분 식물에 건조 경고가 붙으므로 게임 쪽 습도 계산 보정이 필요합니다. 이미 다른 방식이라면 무시해 주세요.
5. 습도 감점이 1년 평균 기준이라 겨울 건조가 묻히는 문제: 난방·건조 거실(건조한 날 8%)에서도 원예 습도 점수 평균이 94점.
   건조 시기 기준으로 감점할지 검토 중입니다.

## 5. ONNX 파일 (`recommend_v1.onnx`)

신경망이 아니라 **위 2~3절의 추천 계산 자체**를 ONNX로 만든 것입니다(원예 규칙 + 식물별 값이 상수로 들어 있음).
신경망을 넘기지 않는 이유: 야외 자생지 기후로 학습한 모델에 실내 날씨를 직접 넣으면 판정을 신뢰할 수 없음을 확인했습니다.

**입력** (B = 놓는 위치 수, 한 번에 여러 위치 가능)
| 이름 | 형태 | 설명 |
|---|---|---|
| `t_min`, `t_max`, `t_mean`, `rh_mean`, `light_lux_mean` | float32 [B, 365] | 2절과 같음 |
| `context` | int64 [B] | 0 = 실내, 1 = 실외 |

**출력** (P = 식물 수, 순서는 `plants.json`)
| 이름 | 형태 | 설명 |
|---|---|---|
| `score`, `light`, `temp`, `humidity` | float32 [B, P] | 총점, 요인별 점수 |
| `gate` | int64 [B, P] | 0 없음, 1 재배구분 불일치, 2 최저기온 < 한계 하한, 3 최고기온 > 한계 상한 |
| `suitable` | bool [B, P] | gate = 0 이고 점수 > 40 |
| `warn_dry` | bool [B, P] | 모델 건조 경고(참고) |
| `room` | float32 [B, 6] | t_min_year, t_max_year, t_mean, rh_mean, rh_dry_p05, light_lux_mean |

**함께 제공:** `plants.json`(식물 순서·학명·모델 건조 한계·코드표), `onnx_verify.json`(검증 결과), `plant_limits_v1_draft.csv`(식물별 원예 한계·모델 한계 표, 78식물).

**검증:** 무작위로 만든 방 2,000개 × 식물 100개를 Python 원본 계산과 ONNX에 같이 넣어 비교 — 점수 차이 최대 0.0002점,
탈락·적합·경고 판정 불일치 0건. 시험 입력은 모든 탈락 종류와 모든 감점 구간을 포함합니다.
규칙이나 한계 값이 바뀌면 다시 내보내고 다시 검증해서 제공합니다.
