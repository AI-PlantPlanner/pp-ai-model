# AIPlant — AI 전달 문서

이 폴더에는 게임 안에서 식물 추천 점수를 계산하는 ONNX 파일과, 그 결과를 읽는 데 필요한 파일이 들어 있습니다.
(자세한 형식은 `io_spec_v1_draft.md`(명세서))

---

## 1. 모델 개요

- 목적: 식물별 기후 견딤 범위(추위·건조 한계)를 자생지 관측 데이터로 추정
- 데이터
  - 식물: 원예팀 100종 자료 중 GBIF 자생지 기록이 충분한 78식물(76종)
  - 자생지: GBIF 관측 기록 → WCVP 원산 판정 + CoordinateCleaner 좌표 정제 → ERA5-Land 0.1° 격자 칸
  - 기후: ERA5-Land 일별 기상 10년(2016–2025, Google Earth Engine) → 칸별 365일 × 기온(최저·평균·최고)·습도
- 모델: 두 인코더 대조 학습(CLIP식 정렬)
  - 기후 인코더: PatchTST(패치 8), 마스크 복원 사전학습 후 미세조정
  - 식물 인코더: 원예 속성 23차원 → MLP
  - 손실: SINR 출현-only 손실(L_AN-full), 종 균형 추출
- 학습·평가: 종 단위 5겹 교차검증 × 시드 5개, 설정은 1-SE 규칙으로 선택(AUC .835±.011)
- 결과 활용
  - 학습한 모델로 식물별 추위·더위·건조 한계 값을 계산
  - 추위 한계는 원예 한계온도와 순위 상관 ρ .857
  - 모델 대신 값을 ONNX에 상수로 넣고, 방 판정은 원예팀 규칙으로 함
    - 이유: 야외 기후로 학습한 모델은 실내 날씨를 직접 판정하지 못함. 반면 한계 값은 방과 무관한 식물 고유 값이라 실내에도 그대로 쓸 수 있기 때문

## 3. ONNX 사용법

### 입력 (B = 한 번에 계산할 위치 수)
| 이름 | 형태 | 단위 | 설명 |
|---|---|---|---|
| `t_min` | float32 [B, 365] | ℃ | 하루 최저기온 |
| `t_max` | float32 [B, 365] | ℃ | 하루 최고기온 |
| `t_mean` | float32 [B, 365] | ℃ | 하루 평균기온 |
| `rh_mean` | float32 [B, 365] | % | 하루 평균 상대습도 |
| `light_lux_mean` | float32 [B, 365] | lux | **낮 평균 밝기**: 조도가 0보다 큰 프레임만 평균 (밤 제외) |
| `context` | int64 [B] | — | 0 = 실내, 1 = 실외 |

- 365일은 1월 1일부터입니다(윤년이면 2월 29일 제외).
- **1년 평균 하나만 넣으면 안 됩니다.** 겨울 한파가 평균에 묻혀, 겨울에 죽는 식물이 추천됩니다.
- **밝기에 밤을 포함하면 안 됩니다.** 원예 적정 광량은 낮 밝기 기준이라, 밤(0 lux)을 넣어 평균을 내면 멀쩡한 방이 어둡다고 판정됩니다.
- 낮 길이는 꽃 피우는 식물의 점수 변환 방법이 아직 정해지지 않아 이번 버전 입력에는 없습니다.

### 출력 (P = 식물 수 100, 순서는 `plants.json`)
| 이름 | 형태 | 설명 |
|---|---|---|
| `score` | float32 [B, P] | 총점 0~100 |
| `light`, `temp`, `humidity` | float32 [B, P] | 요인별 점수 ("왜 점수가 낮은지" 설명용) |
| `gate` | int64 [B, P] | 탈락 코드: 0 없음, 1 재배구분 불일치, 2 최저기온 < 한계 하한, 3 최고기온 > 한계 상한 |
| `suitable` | bool [B, P] | 추천 가능 = 탈락 아님 그리고 점수 > 40 |
| `warn_dry` | bool [B, P] | 모델 건조 경고 (참고용, 점수에는 안 들어감) |
| `room` | float32 [B, 6] | 방 요약: 1년 최저, 1년 최고, 평균기온, 평균습도, 건조한 날 습도(하위 5%), 평균 밝기 |

### 결과 해석
- 출력의 `[b, i]`는 **b번째 위치의 i번째 식물**입니다. i번째 식물이 무엇인지는 `plants.json`의 `plants[i]`(`index`, `name`, `scientific_name`)를 봅니다.
- 점수와 판정은 원예팀 규칙 그대로입니다. 탈락(0점)은 두 가지(한계온도 이탈, 재배구분 불일치)뿐입니다.
- AI 모델(신경망)은 게임에 들어가지 않습니다. 모델이 계산한 식물별 한계 값이 ONNX 안에 상수로 들어있습니다.
  - 이유: 모델은 전 세계 자생지(야외) 기후로 학습했습니다. 실내 방 날씨를 직접 넣어 점검해 보니, 난방 실내 기후는 학습한 범위를 모두 벗어나 판정을 신뢰할 수 없었습니다.
    그래서 신뢰할 만한 영역(식물별 추위·건조 한계 추정)만 미리 계산해 값으로 넣고, 방 판정은 원예팀 규칙으로 합니다.

## 4. 검증 결과

무작위로 만든 방 2,000개 × 식물 100개를 Python 원본 계산과 ONNX에 같이 넣어 비교했습니다.
- 점수 차이: 최대 0.0002점 (계산 정밀도 차이 수준)
- 탈락·추천 가능·경고 판정이 다른 경우: **0건**
- 시험 입력에 모든 탈락 종류와 모든 감점 구간이 들어 있습니다. 자세한 값은 `onnx_verify.json`에 있습니다.

## 5. LLM 템플릿에 쓸 값

문장 틀에 아래 값을 넣습니다. 모든 값은 ONNX 출력과 `plants.json`에서 가져오고, 새로 계산하지 않습니다.

| 문장 종류 | 쓸 값 | 예시 |
|---|---|---|
| 추천 여부 | `suitable`, `score` | "이 자리에 잘 맞아요 (85점)" |
| 탈락: 재배구분 | `gate = 1`, `plants[i].hort.cultivation` | "실외에서 키우는 식물이에요" |
| 탈락: 추위 | `gate = 2`, 방 1년 최저 `room[0]`, `plants[i].hort.temp_limit_lower` | "겨울 최저 3℃가 견딜 수 있는 10℃보다 낮아요" |
| 탈락: 더위 | `gate = 3`, 방 1년 최고 `room[1]`, `plants[i].hort.temp_limit_upper` | "여름 최고 45℃가 견딜 수 있는 41℃보다 높아요" |
| 점수가 낮은 이유 | `light`, `temp`, `humidity` 중 가장 낮은 요인 + 방 값 `room` + 적정 범위 `plants[i].hort` | "빛이 부족해요 (적정 10,000~20,000 lux)" |
| 건조 경고 (참고) | `warn_dry`, 방 건조한 날 습도 `room[4]`, `plants[i].dry_limit_model` | "건조한 시기 습도 35%가 이 식물 자생지의 건조 한계 37%보다 낮아요 (참고)" |

`plants[i].hort` 항목 (원예 자료 값)
| 키 | 설명 |
|---|---|
| `cultivation` | 재배구분: `실내`, `실외`, `실내,실외` |
| `temp_limit_lower`, `temp_limit_upper` | 한계온도 하한·상한(℃). 탈락 판정에 쓰는 값과 같음 |
| `temp_optimal` | 적정 온도(℃), [최소, 최대] |
| `humidity_optimal` | 적정 습도(%), [최소, 최대]. 값이 하나만 기재된 식물은 최대가 `null` |
| `light_lux_optimal` | 적정 광량(lux), [최소, 최대] |

요인 점수(`light`, `temp`, `humidity`) 해석 (원예 판정 기준 단계)
| 점수 | 단계 | 문장 강도 예시 |
|---|---|---|
| 100 | 적정 | "잘 맞아요" |
| 40 이상 ~ 100 미만 | 생육 둔화 | "조금 부족해요 / 조금 높아요" |
| 40 미만 | 생육 정지 | "많이 부족해요 / 너무 높아요" |

- 탈락(`gate ≠ 0`)이면 요인 점수가 모두 0이므로, 요인 점수 대신 탈락 사유만 씁니다.
- 부족인지 과다인지는 점수만으로 알 수 없습니다. 방 값과 적정 범위를 비교해 정합니다.
  - 빛: `room[5]`(평균 밝기) < `light_lux_optimal` 최소 → 부족, > 최대 → 과다
  - 온도: `room[2]`(평균기온) < `temp_optimal` 최소 → 낮음, > 최대 → 높음
  - 습도: `room[3]`(평균습도) < `humidity_optimal` 최소 → 건조, > 최대 → 과습

지킬 것
- 문장 속 숫자는 ONNX 출력과 `plants.json`에 있는 값만 사용. (새로 계산 X)
- 탈락한 식물은 요인 점수가 모두 0입니다. 탈락 사유만 설명합니다.
- 건조 경고는 원예 기준이 아니라 모델 추정입니다. "참고"로 표현하고 단정하지 않습니다.
- 건조 경고는 탈락하지 않은 식물에만 보여 줍니다(탈락 사유가 우선).
- `dry_limit_model`이 `null`인 식물(22개, 자생지 기록 부족)은 건조 경고가 나오지 않습니다.
